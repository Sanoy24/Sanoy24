### 📊 Tenacious-Bench — AI Sales Agent Benchmark & LoRA Judge

> Domain-specific evaluation benchmark + SimPO preference-tuned judge for B2B sales agents. Published dataset & model adapter on Hugging Face.

[![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)](https://github.com/Sanoy24/tenacious-bench)
[![Hugging Face](https://img.shields.io/badge/HuggingFace-FFD21E?style=flat-square&logo=huggingface&logoColor=black)](https://huggingface.co/sanoy24)
[![SimPO](https://img.shields.io/badge/SimPO-LoRA-8B5CF6?style=flat-square&logoColor=white)](https://github.com/Sanoy24/tenacious-bench)
[![Jupyter](https://img.shields.io/badge/Jupyter-F37626?style=flat-square&logo=jupyter&logoColor=white)](https://github.com/Sanoy24/tenacious-bench)

- 📁 **242-task machine-verifiable dataset** across 14 failure dimensions (published: [HF Dataset](https://huggingface.co/datasets/sanoy24/tenacious_bench_v0.1))
- 🧬 **SimPO LoRA fine-tuning** on Qwen2.5-3B — pairwise accuracy 97.73% → **100%** (published: [HF Model](https://huggingface.co/sanoy24/tenacious-judge-qwen25-3b-gamma15))
- ✅ **Inter-rater agreement** κ=0.91, contamination-checked (n-gram + embedding + hash)
- 🔬 **4 dataset generation modes** — programmatic sweeps, trace-derived, multi-LLM synthesis, hand-authored adversarial
- 📝 **Technical blog post** — [Building a 0→100% Accurate AI Sales Judge](https://yonasmekonnen.substack.com/p/building-a-0-100-accurate-ai-sales)
- 💵 **Total training cost: $0.00** (Colab T4, 16.14 min)
