### ⚖️ Automaton Auditor — LangGraph Governance Swarm

> A production-grade **Autonomous Governance Swarm** on **LangGraph** that performs forensic audits of GitHub repos and PDF reports through a hierarchical **Digital Courtroom** multi-agent architecture.

<p>
  <img src="https://img.shields.io/badge/LangGraph-1C3C3C?style=flat-square&logo=langchain&logoColor=white" />
  <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/LangSmith-1C3C3C?style=flat-square&logo=langchain&logoColor=white" />
  <img src="https://img.shields.io/badge/Pydantic-E92063?style=flat-square" />
  <img src="https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white" />
</p>

- ⚖️ **3-layer Digital Courtroom**: Detective fan-out → Judicial panel → ChiefJustice synthesis
- 🔭 **Detective Layer** — AST-based code analysis (not regex), sandboxed `git clone`, PDF ingestion + RAG-lite chunking
- 👨‍⚖️ **Judicial Layer** — Prosecutor / Defense / Tech Lead analyze every criterion independently via `.with_structured_output()` with retry + regex fallback
- 🏛️ **Supreme Court (ChiefJustice)** — deterministic Python rules (Rule of Security, Rule of Evidence, Rule of Functionality) — _not_ LLM prompts
- 📡 **Dynamic multi-LLM factory** — routes to Ollama, Groq, OpenAI, Anthropic, or Gemini per-node
- 🛡️ **Swarm resilience** — exponential backoff on 429s during parallel fan-out

[![View Project](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Sanoy24/trp1-automation-auditor)

### 🏭 Document Intelligence Refinery — Multi-Stage Agentic Pipeline

> Production-grade 5-stage pipeline that ingests heterogeneous document corpora (PDFs, scanned reports, table-heavy docs) and emits structured, spatially-indexed, queryable knowledge.

<p>
  <img src="https://img.shields.io/badge/LangGraph-1C3C3C?style=flat-square&logo=langchain&logoColor=white" />
  <img src="https://img.shields.io/badge/ChromaDB-F97316?style=flat-square" />

  <img src="https://img.shields.io/badge/Pydantic-E92063?style=flat-square" />
</p>

- 🗂️ **Stage 1 — Triage Agent**: classifies document type (native digital, scanned, table-heavy, mixed)
- ⚗️ **Stage 2 — Extraction Router**: confidence-gated page-level escalation — pdfplumber → Docling → Vision LLM
- ✂️ **Stage 3 — Chunking Engine**: semantic chunking with 5-rule constitution + ChunkValidator
- 📇 **Stage 4 — PageIndex Builder**: hierarchical page index + SQLite FactTable for numerical metrics
- 🔍 **Stage 5 — Query Agent** (LangGraph ReAct): 3 tools — `navigate`, `search`, `sql_query`
- 🛡️ Budget guard & YAML-externalized thresholds — onboard new document types without code changes
